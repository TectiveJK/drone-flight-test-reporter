# Contributing to Drone Flight Test Reporter

Thank you for contributing! This project is a prototype desktop application for drone flight-test reporting, and contributions are welcome.

## How to contribute

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and commit them with clear messages.
5. Push your branch to your fork.
6. Open a pull request against `TectiveJK/drone-flight-test-reporter:main`.

## Branch naming

Use descriptive names such as:

- `feature/add-markdown-export`
- `fix/export-pdf-bug`
- `docs/update-readme`

## Code style

- Keep JavaScript code readable and consistent with the existing style.
- Use meaningful variable and function names.
- Add comments for non-obvious logic.

## Testing

- Install dependencies with `npm install`.
- Run the app locally with `npm start`.
- Verify that the app starts and the main UI loads.
- Ensure any added scripts still pass syntax validation.

## Reporting issues

If you find a bug or want a new feature, open an issue on GitHub with:

- A clear title
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if relevant

## Pull request checklist

- [ ] My changes are in a dedicated branch.
- [ ] I added or updated documentation as needed.
- [ ] I verified that the app builds and runs locally.
- [ ] I described the change clearly in the PR.
