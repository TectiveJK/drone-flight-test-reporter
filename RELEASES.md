# Release Notes

## v0.1.0 — Prototype release

Initial prototype release of the Drone Flight Test Reporter desktop app.

### Included features

- Electron desktop application scaffold
- flight/mission metadata form
- telemetry, anomalies, operator notes
- voice note capture and transcription
- Jira ticket link support
- attachment handling and file selection
- Markdown export
- PDF export
- GitHub Actions workflow for syntax validation

## Future planned releases

### v0.2.0

- improved report formatting and templates
